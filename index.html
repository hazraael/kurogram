📖 Les 3 Règles d'Or

Glissez ou utilisez ◀ ▶
Règle 1 / 3 — L'ADN du Sudoku

Unicité des chiffres (même sous un Mur !)

Sur une grille de 4 cases, chaque ligne et chaque colonne contient les chiffres 1, 2, 3 et 4 une seule fois.
⚠️ Important : Un Mur noir ⬛ cache toujours un chiffre ! Ce chiffre masqué compte pour la règle du Sudoku et ne peut plus être utilisé ailleurs sur la même ligne ou colonne.

✅ CORRECT : Les chiffres 1, 2, 3 et 4 sont tous présents une seule fois
1

4
Le 2 🔒 est caché sous le mur : les cases blanches utilisent donc 1, 3 et 4.
❌ INCORRECT : Le chiffre 2 est utilisé deux fois !

4
Interdit : le 2 est déjà caché sous le mur de cette ligne, on ne peut pas le remettre dans une case blanche (et il manque le 3).
Règle 2 / 3 — L'ADN du Nonogram

Les Murs noirs découpent la grille

Certaines cases sont des Murs noirs ⬛ qui séparent les cases blanches en plusieurs blocs.
Si l'indice au bord affiche deux nombres (ex : 1 - 7), il y a obligatoirement au moins un Mur ⬛ entre le premier bloc blanc et le second bloc blanc.

✅ CORRECT : Le mur sépare bien les deux blocs de l'indice « 1 - 7 »

1er bloc blanc à gauche (1), puis un Mur ⬛, puis le 2e bloc blanc à droite (3 et 4).
❌ INCORRECT : Aucun mur ne sépare les deux blocs !

2🔒
Interdit : ici toutes les cases blanches se touchent (cela ferait un seul bloc de somme 1+3+4 = 8 au lieu de 1 - 7).
Règle 3 / 3 — L'ADN du Kakuro

Les Sommes (Le Mur ne s'additionne jamais !)

Les indices sur les bords indiquent la somme des cases blanches de chaque bloc.
⚠️ Règle clé : Le chiffre caché sous un Mur ⬛ ne compte JAMAIS dans la somme (il vaut 0 pour l'addition, même s'il compte pour le Sudoku !).

✅ CORRECT : Seules les cases blanches sont additionnées
1 - 7
1
2🔒
3
4
Bloc gauche = 1. Le mur (2🔒) est ignoré dans la somme. Bloc droit = 3 + 4 = 7 !
❌ INCORRECT : Le chiffre du mur a été compté dans la somme
1 - 7
1
4🔒
3
2
Erreur : les cases blanches de droite font 3 + 2 = 5 (et non 7). Le 4🔒 sous le mur ne s'additionne jamais !
